# Strategy root-cause analysis (fixed, descriptive)

This phase examines existing approved Design A and Design C reports only. It
separates selection, turnover, execution/cash, costs, and market-regime
hypotheses without changing either strategy or rerunning a backtest.

The runner reports fills/non-fills, turnover, commission, VAT, slippage, and
valuation completeness. These are associations, not causal proof. Daily rows
are not treated as independent experiments. A/C differences remain subject to
the pre-registered statistical protocol and the five-fold OOS limitation.

# Current SET50 Universe

The recorded current universe contains exactly 50 securities for the 2026 H2 effective period, 2026-07-01 through 2026-12-31. It is stored in `reports/current_set50_universe.csv` and is derived from SET's H1 2026 constituent list plus the official H2 review changes: additions BCP, MRDIYT, TFG, THAI and removals BTS, CBG, CENTEL, SAWAD.

Sources:

- SET H1 2026 constituent PDF: https://media.set.or.th/set/Documents/2025/Dec/SET50_100_H1_2026.pdf
- SET H2 2026 review: https://www.set.or.th/en/market/news-and-alert/newsdetails?id=105128300&symbol=SET
- SET constituent archive/current-period page: https://www.set.or.th/en/market/information/securities-list/constituents-list-set50-set100

The CSV is a research input, not an order authorization. No broker order capability is enabled by this artifact.
